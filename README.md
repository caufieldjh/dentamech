# DentaMech

Dental Materials Knowledge Base.

DentaMech records dental restoration materials: composition, setting, clinical use, performance, adverse effects, regulatory status and standards, one record per OHD term, with every claim quoted from its source.

DentaMech is a Mech: one validated YAML record per dental material, a
LinkML schema, ontology-grounded identifiers, cited evidence with verbatim
quotes, and an append-only curation history. AI agents write most of it and
people review it through pull requests. It follows the pattern of
[DisMech](https://github.com/monarch-initiative/dismech).

## Layout

| Path | What it is |
|---|---|
| `kb/materials/` | One YAML file per dental material |
| `src/dentamech/schema/dentamech.yaml` | The LinkML schema. Root class `DentalMaterial` |
| `src/dentamech/schema/mech_shared.yaml` | Discussion and Dataset classes, vendored from the Mech fleet |
| `src/dentamech/schema/history.yaml` | The curation history schema, vendored from the Mech fleet |
| `history/` | Append-only curation history, one file per session |
| `conf/oak_config.yaml` | Which ontology service checks which CURIE prefix |
| `cache/`, `references_cache/` | Term and source caches written by the validators |
| `curation/source_queue.tsv` | Ranked sources that feed curation |
| `research/` | Deep-research reports on records, as leads for curators |
| `docs/`, `mkdocs.yml` | The documentation site: guides, plus schema pages generated by LinkML |
| `conf/site.yaml` | How the documentation site and record browser look: colors, theme, columns |
| `pages/` | Record browser from `just render`, for a local look (not committed) |
| `registry/dentamech.md` | Draft entry for MechRegistry |
| `.claude/skills/` | Curation skills for agents |
| `.github/workflows/` | GitHub workflows; `docs/WORKFLOWS.md` describes them |

## Use

```bash
just install
just qc
just validate kb/materials/<record>.yaml
just docs-serve     # browse the documentation locally
```

The documentation is published at
https://caufieldjh.github.io/dentamech/.

## Validation

Validation checks that the record matches the schema, with unknown fields
rejected. Every ontology term exists, sits under the right root and carries
its real label. The record's id sits under OHD:0000000. Every quoted snippet
appears verbatim in its cited source.

Validation does not check that the science is right. DentaMech is
AI-curated. Treat it as a curated draft reviewed by people, not as an
authority.
